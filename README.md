# 🚗 DVLD – Driving & Vehicle License Department System

A desktop application built with C# and Windows Forms to manage the full
lifecycle of driving licenses, from registering a person to issuing,
renewing, and detaining licenses.

## ✨ Features

- **People & Users:** add, edit, search, and manage people and system users,
  with password change and a "Remember Me" login option
- **Local Driving License:** new license applications with test scheduling
  (vision, written, street) and retake tests
- **License Services:** issue a first-time license, renew, and replace
  lost or damaged licenses
- **Detain & Release:** detain a license and release it with fees
- **International License:** issue international licenses for eligible drivers
- **Drivers & History:** list all drivers and view each person's license history
- **Settings:** manage application types and test types with their fees

## 🛠 Tech Stack

- C# / Windows Forms (.NET Framework 4.7.2)
- 3-Tier Architecture: Presentation, Business Logic (BLL), Data Access (DAL)
- [SQL Server / ADO.NET]



## 🚀 Getting Started

1. Clone the repository:
   `git clone https://github.com/AyhamKJeet/DVLD-Project.git`
2. Restore the database from [Database/DVLD.bak or the .sql script].
3. Update the connection string in the Data Access project.
4. Open `DVLD.sln` in Visual Studio and run the project.
